Privacy Policy

Last updated:

This Chrome extension, Bitcointalk BBCode Extension, enhances the posting experience on Bitcointalk.org by adding keyboard shortcuts for BBCode formatting and setting a default Merit value. We take user privacy seriously and designed the extension so that it does not collect, store, or transmit any personal or sensitive data.

Data Collection

The extension does not collect, log, or upload:

  • Personal information
  • Browsing history
  • Form contents or messages
  • IP addresses, cookies, or identifiers
  • Analytics or usage statistics

All actions performed by the extension (such as inserting BBCode tags or changing the Merit input value) occur locally within your browser only.

How Permissions Are Used

The extension requests the minimum permissions necessary to provide its functionality:

  • activeTab – Used to apply BBCode formatting only on the tab where the user is actively composing a message on Bitcointalk.
  • scripting – Used to run a small content script that updates text fields (e.g., wrapping selected text in BBCode tags or setting the Merit field to a default value of 1).
  • Host access to https://bitcointalk.org/ – Required so the extension can interact specifically with Bitcointalk’s post editor and Merit page. The extension does not access or modify data on any other websites.

These permissions are used solely to modify the content of text boxes that you are actively editing on Bitcointalk.org. No data is sent to external servers by the extension.

Third-Party Services

The extension does not integrate with or send data to any third-party services, analytics providers, or advertising networks.

Data Sharing and Sale

Because no data is collected, the extension does not share, sell, or rent any user data to anyone.

Your Rights

Since the extension does not collect or store any data, there is no data to access, modify, or delete. You can remove all functionality of the extension at any time by uninstalling it from your browser.

Contact

If you have questions or concerns about this privacy policy or how the extension works, you can contact the developer via Bitcointalk: https://bitcointalk.org/index.php?action=profile;u=1634314 .
